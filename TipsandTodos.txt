How to switch between local mode and deployed mode
client/.env.local:
Set VITE_SUPABASE_URL="placeholder"
Set VITE_SUPABASE_ANON_KEY="placeholder"

server/.env:
Set SUPABASE_JWT_SECRET="placeholder"
Set DATABASE_URL="postgresql://postgres:midawper56@localhost:5432/prep_tracker?schema=public" (Your local Postgres URL)

and vice versa (comment uncomment)
